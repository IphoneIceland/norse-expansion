# Norse Expansion

An interactive 3D globe of the Viking Age, 793-1200 - routes, battles, settlements, hoards and sagas plotted on a spinning Earth, with animated sweeps that play each direction of Norse expansion in date order.

**Open it: https://IphoneIceland.github.io/norse-expansion/**

One self-contained HTML file. Everything is inlined - the Earth texture, every photo, the code - so it also runs offline if you save it.

It is a big page (about 19 MB). Give it a moment on the first load; after that the browser caches it.

Source, data and build scripts live in a private backup gist. This repo is the viewer.
